The problem

Inventory and production decisions are still made by guesswork.

What goes wrong

Many small and mid-sized manufacturers size orders, set reorder points and plan assembly stations by gut feeling or in scattered spreadsheets. Order too much and cash sits on the shelf. Order too late and the line stops waiting for parts.

Who faces it

Production planners, inventory managers and industrial engineering students who need a correct answer quickly, without building a new spreadsheet model every time.

How OpsLab solves it

Enter a few numbers and get the answer in seconds, with a chart and the formula behind it. The decision is easy to check and easy to explain to a manager or a professor.

    How it works

    The formulas behind each result

    Every calculator uses the standard textbook formula. Each worked example below uses the example values pre-filled in the tool, so you can check the result yourself.

    Economic Order Quantity

    How many units should I order each time?

    Q* = √(2·D·S / H)
    TC = (D/Q)·S + (Q/2)·H
    D
    Annual demand (units/year)
    S
    Cost of placing one order
    H
    Cost of holding one unit for a year
    TC
    Total annual ordering + holding cost
    Worked exampleQ* = √(2·12,000·150 / 4) = √900,000 ≈ 949 units
    That means 12,000 / 949 ≈ 12.6 orders a year. At Q* the ordering cost and the holding cost are equal (₺1,897 each), so TC ≈ ₺3,795.

    Safety Stock & Reorder Point

    When should I place the next order?

    SS = z·σ·√L
    ROP = d·L + SS
    d
    Average daily demand
    σ
    Standard deviation of daily demand
    L
    Lead time in days
    z
    z-score for the service level (95% → 1.645)
    Worked exampleSS = 1.645·8·√5 ≈ 29 units
    Demand during the 5-day lead time is 48·5 = 240 units, so ROP = 240 + 29 = 269. With 400 units on hand, no order is needed yet.

    Overall Equipment Effectiveness

    How much of the planned time is truly productive?

    A = Run time / Planned time
    P = (Ideal cycle × Total units) / Run time
    Q = Good units / Total units
    OEE = A × P × Q
    A
    Availability: losses from breakdowns and changeovers
    P
    Performance: losses from slow cycles and small stops
    Q
    Quality: losses from defects and rework
    Worked exampleRun time = 420 − 47 = 373 min, so A = 88.8%. P = 19,271·1 s / 22,380 s = 86.1%. Q = 18,848 / 19,271 = 97.8%.
    OEE = 0.888 × 0.861 × 0.978 ≈ 74.8%

    Takt Time & Line Balancing

    How many stations does the line need?

    Takt = Available time / Demand
    N_min = ⌈Σt / Takt⌉
    Efficiency = Σt / (N · Takt)
    Σt
    Sum of all task times
    N
    Number of stations actually used
    Rule
    Largest task time first: at each station, add the longest task whose predecessors are done and that still fits within takt
    Worked exampleTakt = 420·60 / 500 = 50.4 s
    The 11 tasks add up to 195 s, so at least ⌈195 / 50.4⌉ = 4 stations. The line fits in 4, giving 195 / (4·50.4) = 96.7% efficiency.
